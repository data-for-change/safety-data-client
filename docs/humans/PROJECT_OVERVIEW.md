# Project Overview — safety-data (client)

Purpose

- Provide an interactive public tool to explore, analyze, and visualize road traffic accidents to identify patterns and support Vision Zero objectives.

Core data

- Person-level records of road accidents (fatalities and injuries).
- Geographic data for streets and intersections.

Main tabs / features

- All country: nationwide aggregates and filters.
- City: per-city exploration and map-focused analysis.
- Recommendations: suggested interventions or insights.
- About: project goals, data sources, privacy, and contact.

Users

- Experts: planners, researchers, and analysts.
- General public: people looking for understandable safety insights.

Common interactions

- Filtering by year, location, vehicle type, road type, and other parameters.
- Viewing results on a map, in a table, or grouped by categories.
